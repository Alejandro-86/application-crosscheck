# crosscheck

A small demo project: cross-check synthetic insurance applications against several sources and flag inaccurate or undisclosed data for a human reviewer.

> Status: work in progress (being rebuilt from an earlier retrieval lab). All data is synthetic; no real patient or employer data is used. Flags are data-quality
> signals for human review, not underwriting decisions.

The README is rewritten at the end of the build; see the commit history for progress.
